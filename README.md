# Alumni Tracking System

## About

The Alumni Tracking System is a web application for managing and tracking university alumni information.

## Features

The system will allow users to:

* Manage alumni information
* View and search alumni
* Create, update, and delete alumni records
* Manage related alumni data
* Access the system through a web interface

## Technology Stack

* **Backend:** C# with ASP.NET Core
* **Database:** PostgreSQL
* **Containerization:** Docker

## How to Run

The project is designed to run with a single command:

```bash
docker compose up
```

More detailed setup and usage instructions will be added as the project is developed.
